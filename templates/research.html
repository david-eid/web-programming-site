CSS At-Rules

At-rules begin with @ and give CSS special instructions. Some end with a semicolon; others contain a block of rules. They can load styles, apply conditions, or describe animations.

/* Apply these styles when printing. */
@media print {
    nav { display: none; }
}

@media

A media query applies styles only when a condition matches. For example, a two-column layout can become one column on a narrow screen.

.notes { display: grid; grid-template-columns: 1fr 1fr; }

@media (max-width: 600px) {
    .notes { grid-template-columns: 1fr; }
}

@import

@import loads rules from another stylesheet. Put it before ordinary style rules. A separate HTML stylesheet link is often preferable because imports can delay loading.

/* At the start of a CSS file: */
@import url("colors.css");

p { line-height: 1.6; }

@keyframes

@keyframes defines stages of an animation. The animation property attaches that named sequence to an element and sets its timing.

@keyframes appear {
    from { opacity: 0; }
    to   { opacity: 1; }
}

.notice { animation: appear 1s ease; }

@media (prefers-reduced-motion: reduce) {
    .notice { animation: none; }
}

<button> vs <input type="button">

Both create clickable buttons. A <button> can contain text and markup, while an <input type="button"> uses its value as a plain text label. Neither example below performs an action until JavaScript is connected.

Set type="button" explicitly on a button that should not submit a form: a regular button inside a form defaults to submitting it.

<button type="button"><strong>Show</strong> details</button>
<input type="button" value="Show details">

<datalist> vs <select>

A <datalist> supplies suggestions for an input, but the user can still enter another value. A <select> asks the user to choose from its listed options. Use suggestions for flexible answers and a select for a fixed set of choices.

<label for="topic">Topic (or enter your own)</label>
<input id="topic" name="topic" list="topics">
<datalist id="topics">
    <option value="CSS"></option>
    <option value="JavaScript"></option>
</datalist>

<label for="level">Level</label>
<select id="level" name="level">
    <option value="beginner">Beginner</option>
    <option value="advanced">Advanced</option>
</select>

JavaScript

JavaScript is a programming language used to add behavior to web pages. In a browser, it can respond to clicks, calculate values, and update the document through the DOM (Document Object Model).

// Update an existing element with id="status".
const status = document.getElementById("status");
status.textContent = "Ready to learn!";

JScript

JScript was Microsoft's implementation of the ECMAScript language, associated with Internet Explorer and Windows scripting. It shared much of JavaScript's syntax, but legacy environments could behave differently. It is a historical topic rather than a choice for this portfolio.

// A simple expression in classic JScript syntax:
var course = "Web Programming";
var message = "Welcome to " + course;

ECMAScript

ECMAScript is the standard that defines the core language implemented by JavaScript. It describes features such as variables, functions, and objects. Browser features such as document are provided by web APIs, not by the core language standard.

// let, const, and arrow functions were introduced in ES2015.
const double = (number) => number * 2;
let score = double(4); // 8

Calling a JavaScript function

Defining a function gives a reusable task a name. Calling it with parentheses runs the task; arguments supply its inputs. An event listener can also call a function when a user clicks a button.

<button type="button" id="greet">Say hello</button>
<p id="greeting" aria-live="polite"></p>

<script>
function greet(name) {
    return "Hello, " + name + "!";
}

console.log(greet("David")); // Direct function call

document.getElementById("greet").addEventListener("click", () => {
    document.getElementById("greeting").textContent = greet("David");
});
</script>

Here the script follows the HTML so the elements exist before it attaches the listener. These snippets are examples to study; they do not execute on this page.
