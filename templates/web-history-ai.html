Introduction

The World Wide Web is a system of interconnected pages and resources that people access through the Internet. It was invented by Tim Berners-Lee while working at CERN in 1989. The Web made it easier to publish, locate, and navigate information using hyperlinks. Technologies such as HTML, HTTP, and URLs became the foundation of the Web. Although the Internet and the Web are closely related, they are not the same: the Internet is the network infrastructure, while the Web is a service that operates on top of it.

Chronological World Wide Web Milestones

1945 - The Memex Concept

In 1945, Vannevar Bush described the theoretical “Memex” in his essay As We May Think. The idea proposed a way for people to store and retrieve information through associative connections. Although the Memex was never built, it anticipated the idea of linking information, which later became important to hypertext and the Web.

Source: https://www.ejsit-journal.com/index.php/ejsit/article/view/287

1965 - The Term “Hypertext” Is Introduced

In 1965, Ted Nelson used the terms “hypertext” and “hypermedia” to describe computerized information connected through links. Hypertext later became one of the fundamental ideas behind the World Wide Web because Web pages are connected to one another through hyperlinks.

Source: https://historyofinformation.com/detail.php?id=830

1980 - Tim Berners-Lee Develops ENQUIRE

While working at CERN in 1980, Tim Berners-Lee developed ENQUIRE, an early hypertext information-management system. ENQUIRE was different from the later World Wide Web, but it contained ideas about linking information that influenced Berners-Lee’s later work.

Source: https://everything.explained.today/ENQUIRE/

1989 - Tim Berners-Lee Proposes the World Wide Web

In 1989, Tim Berners-Lee submitted Information Management: A Proposal while working at CERN. The proposal described a hypertext-based system for connecting and sharing information across computers. This is considered the conceptual beginning of the World Wide Web.

Source: https://home.cern/science/computing/the-birth-of-the-web/

1990 - The Web Becomes a Working System

In 1990, Berners-Lee and Robert Cailliau developed a more formal proposal for the Web. Berners-Lee also developed the first Web browser/editor and the first Web server, together with the core technologies HTML, HTTP, and Web addressing. This transformed the Web from an idea into a functioning system.

Source: https://home.cern/science/computing/the-birth-of-the-web/

1990 - First Web Server and Browser/Editor

The first Web server, httpd, and the first browser/editor, WorldWideWeb, became operational at CERN. The Web server provided documents while the browser allowed users to access and edit linked information.

Source: https://home.cern/science/computing/the-birth-of-the-web/short-history-web/

1991 - World Wide Web Software Is Released

In 1991, World Wide Web software was released.

Source: https://home.cern/science/computing/the-birth-of-the-web/short-history-web/

1993 - CERN Makes Web Software Freely Available

On April 30, 1993, CERN placed key World Wide Web software in the public domain. This allowed organizations and individuals to use, modify, and distribute the technology without paying CERN, helping the Web spread rapidly around the world.

Source: https://home.cern/science/computing/the-birth-of-the-web/short-history-web/

1994 - W3C Is Founded

In October 1994, Tim Berners-Lee founded the World Wide Web Consortium (W3C) at MIT in collaboration with CERN. W3C was created to coordinate open Web standards so that websites and technologies could remain compatible across different browsers, devices, and organizations.

Source: https://www.w3.org/about/history/

1994 - Netscape Navigator

Netscape Navigator became one of the first widely used commercial Web browsers. It helped bring the Web into homes and businesses and contributed to the rapid growth of commercial Web use.

Source: https://www.computerhistory.org/revolution/the-web/20/391

1995 - JavaScript

In 1995, JavaScript was developed at Netscape. It allowed Web pages to respond to user actions and change dynamically, helping the Web evolve from mainly static documents into interactive applications.

Source: https://tc39.es/ecma262/

1995 - Internet Explorer

Microsoft released Internet Explorer in 1995. Competition between Internet Explorer and Netscape accelerated browser development, although differences between browsers also created compatibility problems for Web developers.

Source: https://www.britannica.com/technology/Internet-Explorer

1996 - CSS Level 1

In 1996, W3C published CSS Level 1 as a Web standard. CSS separated the visual presentation of a page, such as colors, fonts, spacing, and margins, from the HTML structure of the content. This made Web design more flexible and maintainable.

Source: https://www.w3.org/TR/REC-CSS1-961217

1996 - Internet Archive

The Internet Archive began preserving websites and other digital material. Because Web pages can change or disappear, Web archiving became important for preserving part of the historical record of the Internet and the Web.

Source: https://archive.org/about/

1997 - JavaScript Is Standardized as ECMAScript

JavaScript was standardized internationally as ECMAScript. Standardization provided browser developers with a common specification for implementing the language and helped improve compatibility between Web applications.

Source: https://tc39.es/ecma262/

1998 - Google Is Founded

Google was founded in 1998. Its search and ranking technology made it easier for users to find relevant information as the number of pages on the World Wide Web increased rapidly.

Source: https://about.google/company-info/our-story/

1999 - Web Content Accessibility Guidelines 1.0

In 1999, W3C published the Web Content Accessibility Guidelines 1.0. These guidelines provided recommendations for making Web content more accessible to people with disabilities.

Source: https://www.w3.org/TR/WAI-WEBCONTENT/

2001 - Wikipedia

Wikipedia was launched in 2001. It demonstrated how large online communities could collaboratively create, edit, and maintain information directly through the Web.

Source: https://meta.wikimedia.org/wiki/Wikipedia_timeline

2001 - Wayback Machine

The Wayback Machine became publicly available and allowed users to view archived versions of websites. This gave researchers and users a way to study how websites and the Web changed over time.

Source: https://librarytechnology.org/document/9384

2004 - WHATWG Is Formed

In 2004, the Web Hypertext Application Technology Working Group, or WHATWG, was formed to continue developing HTML and technologies needed for Web applications. Its work later contributed significantly to HTML5 and the modern HTML Living Standard.

Source: https://whatwg.org/faq

2005 - Google Maps

Google Maps introduced a highly interactive browser-based mapping experience. It demonstrated that Web applications could provide sophisticated, application-like experiences without requiring traditional desktop software.

Source: https://blog.google/products-and-platforms/products/maps/

2007 - iPhone and the Mobile Web

Apple introduced the iPhone in 2007 with a full Web browser and Internet capabilities. Devices such as the iPhone helped accelerate the transition from a Web accessed mainly through desktop computers toward a Web increasingly accessed through mobile devices.

Source: https://www.apple.com/newsroom/2007/01/09Apple-Reinvents-the-Phone-with-iPhone/

2008 - Google Chrome

Google released the Chrome browser in 2008. Chrome increased browser competition and emphasized performance, security, and support for increasingly sophisticated Web applications.

Source: https://blog.google/products/chrome/a-fresh-take-on-browser/

2014 - HTML5

In 2014, W3C published HTML5 as a formal Recommendation. HTML5 added standardized support for features such as audio, video, graphics, improved forms, and application capabilities, helping reduce dependence on proprietary browser plug-ins.

Source: https://html.spec.whatwg.org/multipage/

2015-2016 - Let’s Encrypt and HTTPS Adoption

Let’s Encrypt began providing free and automated digital certificates. This reduced the cost and complexity of implementing HTTPS and helped encrypted Web connections become much more common.

Source: https://letsencrypt.org/about/

Three Key Web Technologies

1. HTML

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure content on Web pages. HTML defines elements such as headings, paragraphs, links, images, and other parts of a Web page. It is one of the core technologies of the World Wide Web.

2. HTTP

HTTP stands for Hypertext Transfer Protocol. It is the protocol used for communication between Web browsers and Web servers. When a user requests a Web page, the browser sends an HTTP request to the server, and the server returns the requested Web content.

3. URL

URL stands for Uniform Resource Locator. A URL gives the address of a resource on the Web. It tells the browser where a Web page or other resource is located so that it can be accessed.
